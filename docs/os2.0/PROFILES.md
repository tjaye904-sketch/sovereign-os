# Deployment profiles

## host-pop
- Daily operator console: Pop!_OS laptop
- CLI, Mission Control, computer-use, voice
- Federation Core may run here initially
- No host disk wipe; install gates enforced
- Profile for Jarvis admin UX

## nixos-sovereign
- Lab and future workspace **node images** (flake / ISO / QEMU)
- Headless nodes bound 1:1 to workspaces
- Not required to replace host-pop for daily admin
