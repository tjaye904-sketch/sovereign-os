# L1.2 Memory facets

Facets (tag `facet:<name>`):

| Facet | Role |
|-------|------|
| constitutional | Long-term architecture / rules |
| working | Active tasks / temp context |
| decision | Decisions / approvals evidence refs |
| operational | Long-lived ops state |
| knowledge | Structured knowledge notes |
| execution | Execution history summaries |

CLI: `memory-facet-add`, `memory-facet-list`, `memory-facet-counts`  
Inspect memory section includes `facet_counts …`
