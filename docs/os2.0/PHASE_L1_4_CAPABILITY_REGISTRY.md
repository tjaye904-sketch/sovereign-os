# L1.4 Capability registry

Persistent `data_root/capability/registry.dat`.

- **Seed** known host/model/cognitive/governance capabilities (enabled by default)
- **Enable / disable** operator toggles
- **IsEnabled** unknown → **false** (fail closed)
- CLI: `capability-seed|list|enable|disable|check`

Later leaps gate computer-use / sys / voice behind these flags.
