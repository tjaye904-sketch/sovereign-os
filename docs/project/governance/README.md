# Sovereign Governance Decisions

This directory contains Governance Decisions (GD).

Governance Decisions define **how the project is managed**.

They are intentionally separate from Architecture Decision Records (ADRs),
which define **how the software is designed**.

Typical Governance Decisions include:

- Engineering process
- Documentation standards
- Audit policies
- Release policies
- Review requirements
- Coding governance
- Project management rules

Governance Decisions are immutable historical records.

New decisions supersede older ones but do not rewrite history.
