2. Installs as primary OS  
3. Starts into Sovereign runtime as primary orchestration  
4. Identity, governance, memory, AI as core OS functions  
5. Full observability and auditability  
6. Requirement → Spec → Implementation → Tests → Trace → Evidence → Docs
