# Sovereign-OS
### A Sovereign, Federated Cognitive Operating System

**Sovereign-OS is a modular, governed, federated cognitive operating system designed to provide persistent intelligence, autonomous coordination, distributed execution, independent identity, policy enforcement, and unified operational control across multiple devices, environments, and federated workspaces.**

Sovereign-OS is not simply an AI assistant, an agent framework, a collection of automation scripts, or a conventional Linux distribution. It is an integrated operating architecture designed to make intelligence, computation, memory, identity, governance, and execution operate as coordinated components of one sovereign system.

Built on a NixOS foundation, Sovereign-OS establishes an independent control plane above the underlying operating system. It coordinates AI models, computational resources, services, applications, agents, persistent state, and distributed infrastructure through a unified runtime and governance architecture.

Its defining principle is:

**Nodes provide compute, not authority.**

Computational resources may be distributed. Workspaces may operate independently. Models and execution environments may change. However, identity, governance, authorization, policy, and sovereign control remain governed by the system's established authority boundaries.

# 10. Architectural Philosophy

Sovereign-OS is guided by several foundational principles:

1. **Sovereignty:** Authority must remain explicitly governed and independent of individual infrastructure providers, models, and participating nodes.

2. **Federation:** Independent environments should be able to participate in a coordinated system without surrendering their defined operational boundaries.

3. **Modularity:** Major capabilities should be implemented as distinct subsystems with explicit responsibilities and interfaces.

4. **Governance by design:** Identity, authorization, policy, and accountability must be architectural concerns rather than afterthoughts.

5. **Persistent intelligence:** The system should maintain operational continuity and structured knowledge beyond individual sessions.

6. **Infrastructure independence:** Intelligence and orchestration should not be permanently coupled to one model provider or computational environment.

7. **Verifiable engineering:** Runtime behavior, state transitions, and subsystem integration should be testable and traceable.

8. **Controlled autonomy:** Autonomous operations must remain within established authority, policy, and capability boundaries.

## Core Architecture
- **C++23 Core Runtime (`core/`, `apps/daemon/`, `apps/cli/`):**
  - **Governance & Capability Gate (`CapabilityRegistry`, `CapabilityGate`, `PolicyEngine`):** Action-level capability enforcement, approval queues, unified desktop application inventory allowlist, and hash-chained tamper-evident `AuditLog`.
  - **Multi-Node Federation (`NodeRegistry`, `PeerAuth`, `PlanRouteDecision`):** Token-authenticated peer node enrollment, capability-aware workspace plan routing, and remote governed execution.
  - **Closed-Loop JARVIS Runtime (`PurposeRuntime`, `ActionExecutor`, `CuriosityEngine`, `DesktopOperatorGateway`):** Seeded purpose packs, post-act FNV-1a verification receipts, policy-bounded curiosity probes, live `wmctrl` window/A11y drive, and local Piper TTS (`en_US-lessac-medium.onnx`) audio routing.
  - **Autonomous Local Model Router (`ModelRouter`, `sovereign-cli chat-tools`):** Multi-turn tool dispatch and synthesis loop backed by local Ollama models.
- **Unified Mission Control (`tools/mission_control/`):** Live dashboard (`http://localhost:8769/ui`) for Doctor hardening diagnostics, governance approvals, federation & fleet status, desktop/voice telemetry, and capability toggles.
- **NixOS Flake (`flake.nix`, `nix/modules/`):** Reproducible `.#iso` (hybrid UEFI/BIOS live ISO) and `.#sovereign-node-vm` (hardened headless QEMU/KVM worker node).

## Quickstart (Linux Host Build & Test)
```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j\$(nproc)
ctest --test-dir build --output-on-failure
```

## Run Host Services & Mission Control
```bash
./scripts/sovereign-session-ensure.sh
./build/apps/cli/sovereign-cli doctor --fix
# Open http://localhost:8769/ui in your browser
```

## Build Bootable NixOS ISO or Node VM
```bash
nix build .#iso
nix build .#sovereign-node-vm
```
Or download the prebuilt `sovereign-os-2.0-0f246fd-x86_64.iso` from **GitHub Releases**, verify `SHA256SUMS`, and write it to a USB drive or SD card using `./scripts/sovereign-flash-usb.sh --yes-flash /dev/sdX`.
