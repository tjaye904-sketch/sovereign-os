# Sovereign Work Sandbox Policy

This repository is an **independent working copy** for engineering under GD-001.

## Rules

1. The original Sovereign repository / archive is **read-only** relative to this work.
2. Nothing in this sandbox may be copied back to the original tree unless the owner
   explicitly requests a merge or promotion.
3. All code creation, implementation, edits, deletes, and moves for ongoing work
   happen **only** in this repository (`sovereign-work`).
4. Canonical project documents (Vision, Bootstrap, Status, Identity spec, GD-001)
   live here and are authoritative for sessions working in this sandbox.
5. Runtime Platform v1 code is present as the substrate; product Identity work
   proceeds here without modifying any external original path.

## Origin

Seeded from the uploaded sovereign archive (active trees only: core, testing,
tools, scripts, docs). Excluded: `.sovereign-mesh`, `releases`.
